# House conventions (from parakeet.cpp / moss-tts.cpp survey)

Template repo: **parakeet.cpp** (most mature). Copy patterns from:
- Converter: `~/_git/parakeet.cpp/scripts/convert_parakeet_to_gguf.py`
- CMake: `~/_git/parakeet.cpp/CMakeLists.txt` (+ moss-tts.cpp for LocalAI backend-link loop + install)
- C-API: `~/_git/parakeet.cpp/include/parakeet_capi.h`
- Parity: `~/_git/parakeet.cpp/tests/parity.hpp` + `tests/CMakeLists.txt`
- Tokenizer embedding: `~/_git/moss-tts.cpp/scripts/convert_tokenizer.py`
- Selective quant: `~/_git/moss-tts.cpp/scripts/quantize_gguf.py`

## Layout
`src/` (common, backend, model_loader, audio_io, magpie_tts.cpp, magpie_tts_capi.cpp),
`include/` (magpie_tts.h + magpie_tts_capi.h only), `examples/cli/`, `tests/` (flat
test_*.cpp + fixtures/), `scripts/`, `docs/`, `benchmarks/`, `third_party/ggml`
(git submodule, ggml-org/ggml pinned to v0.13.0 = commit e705c5fed4...).

## GGUF
- `gguf.GGUFWriter(out, "magpie-tts")`; KV keys dotted under `magpie.*`
  (e.g. `magpie.decoder.n_layers`, `magpie.codec.*`, `magpie.tokenizer.*`).
- Tensor names verbatim from state_dict where possible.
- Quantization: allowlist of regexes — only `ggml_mul_mat` weights get f16/q8_0+;
  raw-`float*` tensors stay F32.
- Tokenizer embedded as GGUF arrays (`magpie.tokenizer.tokens`, ids, etc). Nothing external.

## C-API
`extern "C"`, opaque `magpie_tts_ctx`, prefix `magpie_tts_capi_*`:
`abi_version(void)`, `load(path)`, `free(ctx)`, work fns returning malloc'd data +
`free_string`/`free_audio`, `last_error(ctx)`. ABI changelog documented in header.
Never let exceptions cross. Designed for dlopen/purego (LocalAI).

## CLI
`magpie-cli <subcommand>`: `say|info|bench|quantize`. Hand-parsed flags
(`--model`, `--text`, `--lang`, `--speaker`, `--threads`, `--output`).
Exit codes: 0 ok, 2 usage, 1 runtime.

## Parity tests
- Reference dumps stored as GGUF (tensors+KV), generated by `scripts/gen_*_reference.py`.
- Dump path via env var (`MAGPIE_REF_DUMP`); test skips with exit 77 if unset
  (`SKIP_RETURN_CODE 77` in CMake).
- Compare with atol+rtol, max/mean abs diff reporting; token streams compared exact.

## Build
C++17, Release default, PIC on, static lib default (`MAGPIE_SHARED` option),
`GGML_LLAMAFILE ON`, `GGML_NATIVE ON`, backend toggles `MAGPIE_GGML_CUDA/METAL/VULKAN/HIP`
forwarded to ggml with CACHE FORCE, `GGML_BUILD_TESTS/EXAMPLES OFF`. For LocalAI:
static-link ggml backends into the .so (foreach backend target_link_libraries loop),
`-Wall -Wextra -Wpedantic -Wno-unused-parameter`.
